# Demo yang dapat diulang — 9 menit

Persiapan: ekstrak paket, buka dengan folder demo terisolasi seperti USER_GUIDE. Daftar akun fiktif001, siapkan semester3 dan empat course: Algoritma3SKS, Basis Data3SKS, PBO3SKS, Bahasa Inggris2SKS. Jangan memasukkan data nyata. Siapkan PNG/JPEG buatan sendiri. Ulangi pada akun baru bila ingin mulai bersih, tanpa menghapus data lama.

| Waktu | Aksi dan hal yang dijelaskan |

| 2:30–3:30 | Simulasi Nilai: course lain mode huruf langsung, simpan A aktual/perkiraan untuk Algoritma/Basis Data dan B untuk Bahasa Inggris. Jelaskan aktual di tab utama, estimasi di skenario. |
